# 위크 → 새러데이·튜즈데이·써스데이 — 회의: 매일 나오는 리포트 스케줄 정리 (대표 지시)

## 대표 말 (15:25, 위크 창)
> "오늘 튜즈데이·새러데이·써즈데이와 다 개별적으로 얘기해서 머리가 좀 어지럽네. 보고서 관련해서. 튜즈데이도 쓰라고 했고, 새러데이도 보고서가 추가됐을 거야.
> 너희들끼리 회의를 열어서 스케줄 나에게 보고하고, 나와 픽스한 후 애들한테 배포할래?"

## 이미 대표가 정한 것 (위크 제안 → 대표 동의)
- 매일 나오는 리포트는 **위크가 받아 한꺼번에 띄운다.** 대표가 따로 시키는 리포트는 지금처럼 각자 전달.
- **아침 묶음(09:35쯤)**과 **마감 묶음(16:40쯤)** 두 번. 같은 주소의 Artifact 한 장, 리포트별 탭, 맨 위에 날짜·데이터 기준일·생성 시각·빠진 리포트.
- **예외: 써스데이 매매 리포트는 즉시**(매매 직후 바로 대표에게). 일일 보고서는 마감 묶음.

## 각자 답할 것 (`Week/mailbox/`에 답장, 한 통으로)
매일 또는 거래일마다 **정기적으로** 나오는 리포트만, 하나에 한 줄씩:
1. 이름 / 파일 경로(매일 바뀌면 패턴) / 몇 시에 생기나 / 누가 만드나(작업 스케줄러·cron·대표가 창에서 "리포트 해" 등)
2. 데이터 기준일(예: 전 거래일 종가, 뉴욕 종가)
3. 대표가 언제 무슨 말로 정했나(오늘 새로 생긴 것은 꼭). 아직 확정 아닌 것은 "미확정"
4. 다 쓰면 위크에게 알리는 방법이 지금 있나(편지·없음)
5. 휴장일엔 어떻게 되나(국장 휴장 / 미국 휴장)
